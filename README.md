# HUSION コーポレートサイト リニューアル デザインドラフト

株式会社ヒュージョン コーポレートサイトのリニューアル案です。デザイン確認用のドラフトとして作成しています。

## 開き方

`husion_corporate_site_draft.html` をダブルクリックするか、ブラウザにドラッグ&ドロップしてください。画像はすべてファイル内に埋め込まれているため、このHTML1ファイルだけで全ページを確認できます（日本語フォントはGoogle Fontsから読み込むため、インターネット接続時に本来の見た目になります）。

画面右上のタブ（TOP／ABOUT／BUSINESS／TECHNOLOGY／PRODUCT／CASE STUDY／NEWS）でページを切り替えて確認できます。

## 現在の収録ページ

- TOP
- ABOUT（HUSIONについて・会社概要）
- BUSINESS（Healthcare／AI・Vision／Robotics／その他）
- TECHNOLOGY（rPPGの仕組み・技術思想）
- PRODUCT（PrimeVital／Prime-rPPG／Smart Mirror）※一部実際の製品写真を使用
- CASE STUDY（導入事例）
- NEWS（お知らせ）

## 注意事項

- 今回のスコープではサーモグラフィー事業（GUARD19シリーズ）は含めていません。
- PRODUCT／CASE STUDY／NEWSの一部の内容（料金・事例・記事）は、デザイン確認用の仮データです。実際の内容は別途確定します。
- デザインは rams design（https://www.ramsdesign.co.jp/）のトーンを参考にしていますが、模写ではありません。
